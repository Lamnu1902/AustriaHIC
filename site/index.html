How photos are picked

Every six hours a GitHub Action searches for nature photos captured in the last week, ranks them, and publishes the winner for each region. If nothing qualifies, the window widens to two weeks, then a month.

Rotation

Each refresh shows the next photo from the top four, so the page changes four times a day even when the shortlist doesn't.
